Every prediction lane is a retained full-vocabulary measurement from the same recorded prefix. At captured forks, a counterfactual lane recursively generates from that run’s winning token, then is discarded so the recorded path can resume. Counterfactual tool calls were never executed: the viewer can grade their structure, but cannot invent a runtime result. “Probability” is each run’s own winning-token probability.
